
# FitnessCoach
Кросплатформний застосунок для організації роботи фітнес-тренерів і взаємодії з клієнтами. Програмний продукт призначений для автоматизації основних процесів фітнес-послуг: управління тренувальними планами, підписками та тренувальними сесіями.

## Мета проєкту
Метою розробки є створення зручного програмного інструменту для організації роботи фітнес-тренерів, автоматизації управління тренуваннями та забезпечення ефективної взаємодії між тренерами й клієнтами.
Застосунок використовує єдину кодову базу та сучасні підходи до проєктування програмного забезпечення, що створює основу для подальшого розвитку й підтримки різних платформ.

## Основні можливості
- Управління тренувальними планами.
- Організація тренувальних сесій.
- Управління підписками та платежами.
- Робота з обліковими записами користувачів.
- Розмежування доступу для клієнтів і тренерів.
- Навігація між основними функціональними модулями.
- Зберігання та обробка даних про користувачів і тренувальний процес.

## Технології

| Технологія | Призначення |
|---|---|
| C# | Основна мова програмування |
| .NET MAUI | Розробка кросплатформного інтерфейсу |
| XAML | Опис інтерфейсу користувача |
| MVVM | Організація взаємодії між інтерфейсом і логікою застосунку |
| .NET | Платформа розробки та виконання |

## Архітектура
У проєкті застосовано архітектурний патерн **MVVM (Model–View–ViewModel)**, який забезпечує розділення інтерфейсу користувача та бізнес-логіки.
Модель даних передбачає зберігання інформації про користувачів, тренувальні плани, підписки та платежі.

## Ролі користувачів
Застосунок передбачає розмежування доступу відповідно до ролей:
- **Тренер** — робота з тренувальними планами та організація тренувального процесу.
- **Клієнт** — використання функцій, пов’язаних із власними тренуваннями та підпискою.
Доступні можливості визначаються роллю користувача.

## Тестування
У межах розробки проводилося функціональне, інтеграційне та нефункціональне тестування.
Перевірялися коректність бізнес-логіки, взаємодія компонентів, стабільність роботи та відповідність визначеним вимогам. Кросплатформне тестування включало перевірку роботи застосунку в середовищі Windows.

## Запуск проєкту
Для відкриття та запуску FitnessCoach необхідні:
- Visual Studio з підтримкою .NET MAUI;
- встановлений відповідний .NET SDK;
- компоненти розробки для цільової платформи.

Клонуйте репозиторій:
```bash
git clone https://github.com/Pashurka/FitnessCoach.git
```

Відкрийте solution-файл у Visual Studio, відновіть NuGet-пакети та виберіть цільову платформу для запуску.
